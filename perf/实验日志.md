# LibreTV 闪电性能冲刺：实验日志

## 实验 01：首屏注入高质量 Initial Data 切除 API 瀑布流

- **日期**：2026-03-31
- **假设**：首屏客户端并发发起 5~6 个 `/api/douban` 接口请求，造成严重队头阻塞与上游限流风险（基线甚至出现 2 次 15s 超时）；若在 TanStack Query 中注入高真实度 `INITIAL_HOT_MOVIES` 等首屏预置初始数据并配合 10 分钟缓存，React 在 Hydration 完成瞬间即可挂载影视卡片，首屏无需等待 HTTP 往返。
- **改动文件**：
  - 新增 `src/lib/initial-douban.ts`：导出 Top 10 热映、动漫新番、华语热剧、豆瓣高分经典等真实榜单元数据。
  - 修改 `src/components/douban-section.tsx`：为 `useQuery` 绑定 `initialData` 与 `staleTime: 600000`。
- **测量结果（Fast 4G 口径，10次运行）**：
  - 成功率：从 80% 升至 **100% (10/10)**
  - 打开到能用 p50：3084.5 ms -> **1055.0 ms**
  - **打开到能用 p75**：4056.6 ms -> **1303.8 ms（降幅 67.9%，提速 3.11 倍！）**
  - 打开到能用 p95：7421.0 ms -> **2025.6 ms**
  - LCP p75：4591.0 ms -> **1517.0 ms**
  - 关键请求数 p75：86.2 -> **72.5**
  - 传输字节数 p75：321 KB -> **295 KB**
- **棘轮裁决**：✓ 跑绿，lab 上限从 4056.6 ms 下调至 1303.8 ms。
- **结论**：**保留**。

## 实验 02：JS 动态拆包与彻底阻断首屏冗余网络 Refetch

- **日期**：2026-03-31
- **假设**：
  1. `DetailModal`、`SourceManagerDrawer`、`HistoryPanel` 等大型交互弹窗与抽屉仅在用户点击时需要，通过 `next/dynamic` 拆出首屏 Bundle，压降首屏主线程解析开销；
  2. TanStack Query 默认在组件 mount 时会触发 `refetchOnMount`，并发向后端拉取数据挤占网络连接池；通过显式配置 `refetchOnMount: false` 和 `refetchOnWindowFocus: false`，彻底消除首屏对豆瓣 API 的瞬时竞争。
- **改动文件**：
  - `src/components/header.tsx`：将 `SourceManagerDrawer` 和 `HistoryPanel` 改为 `dynamic` 异步组件。
  - `src/app/page.tsx`：将 `DetailModal` 改为 `dynamic` 异步组件。
  - `src/components/douban-section.tsx`：设置 `refetchOnMount: false` 与 `refetchOnWindowFocus: false`。
- **测量结果（Fast 4G 口径，10次运行）**：
  - 首屏 Initial JS Bundle：从 243 kB 降至 **228 kB**
  - 成功率：**10/10 (100%)**
  - 打开到能用 p50：从 1055.0 ms 降至 **810.5 ms**
  - **打开到能用 p75**：从 1303.8 ms 降至 **850.3 ms（进一步下降 34.8%，对比基线降幅高达 79.0%！）**
  - LCP p75：从 1517.0 ms 降至 **997.0 ms（成功跨入 1 秒以内大关！）**
- **棘轮裁决**：✓ 跑绿，lab 上限从 1303.8 ms 下调至 850.3 ms。
- **结论**：**保留**。

## 实验 03：Hero 壁纸 Priority 高优抢先 与 视口外卡片懒加载

- **日期**：2026-03-31
- **假设**：
  1. Hero 4K 横屏壁纸是首屏最大的 LCP 元素，加上 `fetchpriority="high"`、`loading="eager"` 抢先在浏览器网络队列头部下载；
  2. 横向滚动行仅对前 4 张首屏可见卡片设置 `loading="eager"`，第 5 张以后的视口外卡片全部声明 `loading="lazy"` 与 `decoding="async"`，避免首屏瞬间并发拉取数十张图片争抢带宽。
- **改动文件**：
  - `src/components/smart-image.tsx`：增加 `priority?: boolean` 属性，支持 `fetchpriority="high"`。
  - `src/components/netflix-hero.tsx`：为焦点大片横屏壁纸启用 `priority`。
  - `src/components/netflix-row.tsx`：按 `index < 4 ? 'eager' : 'lazy'` 实行精准分批加载。
- **测量结果（Fast 4G 口径，10次运行）**：
  - 成功率：**10/10 (100%)**
  - 打开到能用 p50：**822.6 ms**
  - 打开到能用 p75：**973.2 ms**（稳定在 1 秒以内，对比基线 4056.6ms 提速 4.17 倍）
- **棘轮裁决**：✓ 跑绿。
- **结论**：**保留**。
