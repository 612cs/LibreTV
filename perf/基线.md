## 2. 首屏关键路径拆解（Resource Timing）

通过对首屏 86+ 个资源的完成时序（`responseEnd`）分析，关键耗时路径如下：

1. **HTML 初始加载**：~250ms (8.9 KB)；
2. **静态 JS Bundle 并行下载与解析**：
   - `chunks/1255-d79dcd6d24226f10.js` (46.1 KB)
   - `chunks/4bd1b696-f6bedae49f0827a5.js` (54.2 kB)
   - 客户端 React Hydration 完成：~600ms；
3. **首屏客户端 API 瀑布流（最大耗时瓶颈）**：
   - 客户端挂载后同时发起 6~8 个 `/api/douban` 请求；
   - 每一个请求独立打到服务端，服务端再去请求豆瓣，遭遇豆瓣上游限频或排队；
   - 耗时在 800ms ~ 3200ms 不等；
   - 只有等首批数据返回后，`.netflix-card` 才能挂载到 DOM 上！
